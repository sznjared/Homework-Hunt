HOMEWORK HUNT - APK builder

Pinakamadali (walang install sa computer):
1. Gumawa ng libreng account sa github.com, mag-New repository (e.g. homework-hunt).
2. I-upload ang LAHAT ng laman ng folder na ito (kasama ang .github, www, package.json, capacitor.config.json).
3. Pumunta sa tab na "Actions" > "Build APK" > hintayin (mga 5 minuto) hanggang green check.
4. Buksan ang run > sa ilalim ng "Artifacts" i-download ang HomeworkHunt-apk > unzip > app-debug.apk.
5. Ipasa sa phone, i-install (payagan ang "Install unknown apps").

Kung may Android Studio ka: npm install; npx cap add android; npx cap sync; npx cap open android.
Gumagana offline ang laro (kasama na ang three.js at lahat ng voice).
